# What If? — Life Decision Simulator

An interactive financial simulator that lets users explore how hourly pay, work hours, taxes, and monthly expenses affect their finances. Adjust the variables to see live calculations, compare scenarios, and visualize potential financial outcomes.

## About This Project

What If? was created as part of the **AI Skills Studio on Handshake**. The application was built with **Google Gemini Canvas**, using AI-assisted development to turn a concept into a working interactive data visualization tool.

The project explores how interactive controls, dynamic charts, and real-time calculations can make financial trade-offs easier to understand.

**Live Demo:** https://share.gemini.google/DW1rALshTDOS

## Features

- **Interactive Controls:** Adjust hourly pay, weekly working hours, monthly expenses, and other available variables.
- **Real-Time Calculations:** See financial metrics update as inputs change.
- **Dynamic Charts:** Visualize monthly cash flow, time allocation, and projected financial outcomes.
- **Scenario Comparison:** Save a baseline and compare changes against different scenarios.
- **Preset Scenarios:** Explore predefined work and lifestyle situations.
- **Financial Insights:** Examine break-even points and the relationship between income, expenses, and available time.
- **Responsive Interface:** Explore the dashboard across different screen sizes.

## Technologies Used

- HTML
- CSS

## How to Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Adjust the interactive controls to explore different scenarios.

Some charts or features may require an internet connection if the application loads external libraries from a CDN.
